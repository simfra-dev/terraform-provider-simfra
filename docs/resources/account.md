# simfra_account (Resource)

Manages a Simfra account. Accounts are the top-level organizational unit in Simfra, equivalent to AWS accounts. Each account has its own 12-digit account ID, root credentials, and isolated resource namespace.

When `bootstrap` is set to `"standard"`, the account is provisioned with default VPC infrastructure (VPC, subnets, internet gateway, route table, security group, and NACL) in the specified region, matching the default resources AWS creates for new accounts.

All attributes on this resource force replacement -- accounts cannot be updated in-place.

## Example Usage

```terraform
resource "simfra_account" "dev" {
  account_id = "123456789012"

  bootstrap        = "standard"
  bootstrap_region = "us-east-1"
}

output "root_access_key_id" {
  value = simfra_account.dev.root_access_key_id
}

output "root_secret_access_key" {
  value     = simfra_account.dev.root_secret_access_key
  sensitive = true
}
```

## Schema

### Optional

- `account_id` (String) -- The 12-digit AWS account ID. Generated by Simfra if not specified. Changing this forces a new resource.
- `bootstrap` (String) -- Bootstrap mode. Set to `"standard"` to create default VPC, subnets, and other resources on account creation. Changing this forces a new resource.
- `bootstrap_region` (String) -- AWS region for bootstrap resources. Required when `bootstrap` is set. Changing this forces a new resource.
- `availability_zones` (List of String) -- Availability zones for bootstrap. Defaults to the region's standard AZs. Changing this forces a new resource.
- `vpc_cidr` (String) -- VPC CIDR block for bootstrap. Defaults to `172.31.0.0/16`. Changing this forces a new resource.

### Read-Only

- `root_access_key_id` (String, Sensitive) -- Root user access key ID.
- `root_secret_access_key` (String, Sensitive) -- Root user secret access key.
- `created_at` (String) -- Account creation timestamp.

## Import

Accounts can be imported using the account ID:

```shell
terraform import simfra_account.dev 123456789012
```
